## Changes

### 2. Daily loop integration (correct order)
`app/scripts/daily_loop.mjs` step 0 is now `import:external`, running **before**
`backtest` and `score:strategies`. It imports the three idea-source seed files
(tradingview / traderdev / generic) from `engine/data/`. Each run is logged to
`SchedulerRunLog` (verified: 3 `import:external` entries + 6 native steps, all OK).

### 3. Idempotent + labeled external imports
`app/scripts/import_external.mjs`:
- Buckets by `imported_date` and de-dupes same-day re-imports (looks up existing
  `ExternalImport` by `source+strategy_name+symbol+imported_date`; replaces its
  `ImportReScore` rows). Verified: re-running the daily seeds keeps today's row
  count stable (idempotent).
- Every imported row is `is_external=1`, tagged with `source` (tradingview /
  traderdev / generic), and re-scored via the engine's `re_score` (our cost model).
  Verified at runtime: every external return is reduced by our cost gap
  (re_costed ≤ external headline) — no bypass.

### 4. Schema migration
`ExternalImport.imported_date TEXT` added (guarded `ALTER` + backfill in
`app/scripts/db_migrate.mjs`; fresh DBs get it from `schema.sql`). Idempotent;
safe to re-run. No table rebuild / no data loss.

### 5. Dashboard badges
- Added `.legend` to `globals.css`; reused existing `.badge.ext` / `.badge.native`.
- Overview (`app/page.tsx`): native/ext legend + "External seeds" stat.

  <re_costed>` badge; dedupe to latest re-score per strategy+symbol (no dup rows).
