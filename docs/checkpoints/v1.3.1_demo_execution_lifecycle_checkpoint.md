# v1.3.1 — Demo Execution Lifecycle Verification (mock forward-testing)

**Date:** 2026-07-10
**Scope:** Full deterministic lifecycle of a paper signal through the demo bridge
(place → simulate close → update → journal), with a rerun-safe proof row, dashboard
quality section, and daily-report execution-quality block. Demo-only, no live, hard locks.

## What was added
- `engine/run_execution.py::mock-lifecycle` command: takes an existing paper `Signal`,
  runs `run_pretrade_guards` (deterministic risk engine), places a **mock** demo order,
  simulates a TP exit + close, and writes an `ExecutionJournal` row comparing expected
  paper PnL vs actual demo PnL (spread/slippage/latency recorded).
- `npm run execution:mock-lifecycle -- --signal-id N [--run-id X] [--force]`.
- `ExecutionJournal` extended: `broker`, `broker_mode`, `run_id`, `price_exit`;
  migration rebuilds the table to enforce `CHECK (broker_mode='demo')` (never-live).
- Dashboard `/demo-execution`: "Completed demo lifecycle checks" — execution quality
  badge, paper-vs-demo PnL delta, avg slippage, avg spread, rejection count, worst
  slippage, and a "Lifecycle journal (mock only)" table. Explicitly labelled
  **NOT real broker fills**.
- Daily report `report_daily.mjs`: "Demo execution quality" block separating **MOCK
  (simulated, not a real venue)** from **REAL DEMO BROKER**, paper-vs-demo mismatch,
  worst slippage, broker/mode, kill-switch status.

## Rerun-safety
A `run_id` (auto-generated UUID unless passed) keys the completed `ExecutionJournal` row.
Re-running the SAME run_id prints `skipped` and creates no duplicate proof row; a new
run_id starts a fresh proof. Verified: rerun of `v131-lc-1` → 1 row only.

## Safety locks (verified)
- `broker_mode='demo'` enforced by DB CHECK on both `DemoExecutionOrder` and
  `ExecutionJournal` (attempting `live` insert raised IntegrityError).
- `cmd_mock_lifecycle` refuses if `allow_live_orders` true, `broker_mode != demo`,
  or kill-switch engaged.
- No secret columns; only `raw_response_redacted_json` stored; paper PnL computed from
  the paper signal, never the broker fill.
- Dashboard states mock fills are simulated, not real broker fills.
- Real-broker (Deriv/OANDA) adapters remain fail-loud-only; bridge ran on mock.
