# v1.3.2 — OANDA Practice + MT5 Demo Execution Adapters

**Date:** 2026-07-11
**Scope:** Run paper signals through REAL DEMO BROKER accounts (OANDA Practice,
MT5 demo) with hard demo-only safety, while keeping the mock adapter authoritative
for deterministic forward-testing.

## Safety guarantees (all preserved)
- `broker_mode` hard-locked to `demo` (DB `CHECK` on `DemoExecutionOrder` +
  `ExecutionJournal`; engine constants).
- No live broker mode. `allow_live_orders`/`ALLOW_LIVE_ORDERS` checked; any
  `live` insert is rejected by SQLite `CHECK`.
- Paper-only: `expected_paper_pnl` computed from the paper signal, never the
  broker fill. Broker secrets never stored (env vars only, redacted in logs/UI/report).
- Locked scoring weights untouched.
- No random exploration trades. Adapters only place approved paper signals that
  already passed `risk_check`.
- Every demo order requires stop_loss + take_profit (guards).
- Max open trades enforced globally AND per-broker.
- Kill switch blocks ALL broker demo execution.
- `BROKER_EXECUTION_MODE` default `observe_only` (never places).
- Duplicate (signal,broker,run_id) prevented via `DemoExecutionLock` UNIQUE.

## What was added
- `engine/src/execution/capabilities.py` — broker capability registry
  (`BrokerCapability` dataclass); `capabilities()` probes mock/OANDA/MT5 and
  stores `BrokerCapability` rows (no secret values; `last_error_redacted`).
- `engine/src/execution/oanda_practice.py` — practice-only adapter; symbol map
  (EURUSD→EUR_USD, GBPUSD→GBP_USD, USDJPY→USD_JPY, AUDUSD→AUD_USD,
  USDCAD→USD_CAD, XAUUSD→XAU_USD with existence check); live host
  `api-fxtrade.oanda.com` rejected; orders only when DRY_RUN=false +
  DEMO_AUTOTRADE_ENABLED=true.
- `engine/src/execution/mt5_demo.py` (renamed from deriv_mt5) — connects to a
  DEMO MT5 terminal; rejects live accounts; configurable symbol map
  (`MT5_SYMBOL_MAP` env); missing terminal/SDK fails loud; gates on
  DEMO_AUTOTRADE_ENABLED.
- `engine/src/execution/factory.py` — adapter selection; execution modes
  (observe_only/dry_run/single_broker_demo/mirror_demo); `can_place_real_demo()`.
- `engine/src/execution/guards.py` — per-broker open cap; SL/TP required.
- `engine/run_execution.py` — commands: broker-check, oanda-check, mt5-check,
  demo-quotes, real-demo-dry-run, real-demo-order, mirror-demo-order,
  journal (filter broker), update (persist caps).
- `app/schema.sql` + `db_migrate.mjs` — `BrokerCapability`, `DemoExecutionLock`,
  `ExecutionControl` new columns (execution_mode, primary_demo_broker,
  max_open_per_broker).
- `app/lib/db.ts` — capability/per-broker/spread/latency/PnL accessors.
- `app/app/broker-demo/page.tsx` + Nav entry — readiness, quotes, spread/slippage
  compare, open by broker, PnL vs OANDA/MT5, slippage compare, kill switch,
  labels NEVER LIVE / REAL DEMO BROKER / MOCK.
- `app/scripts/report_daily.mjs` — broker-demo block (mode, primary, OANDA/MT5
  status, demo orders, rejections, avg spread/slippage per broker, mismatch,
  winner, kill-switch).
- Tests: 16 new pytest (creds missing fail loud, terminal missing fails loud,
  live host rejected, symbol map, DRY_RUN/autotrade gates, kill switch blocks,
  per-broker cap, no secret columns, broker failure can't fake fill, duplicate
  lock, mock lifecycle still passes); 9 new app safety tests.
