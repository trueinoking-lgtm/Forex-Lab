## 7. Forecast Output Shape Clarification

shape = (5, 6)

Six columns:
1. open — Kronos model output
2. high — Kronos model output
3. low — Kronos model output
4. close — Kronos model output
5. volume — Kronos model output (synthetic, mean ≈ 0)
6. amount — Kronos model output (synthetic, mean ≈ 0)

All 6 columns are generated by the Kronos model. No real future OHLC values are present in the forecast output. Real future OHLC values exist only in a separately labelled scoring target file for evaluation, never inside the model forecast output.

Five forecast rows correspond to the five held-out D1 timestamps (2026-07-20 through 2026-07-24, a Monday-Friday window with zero weekend bars).
